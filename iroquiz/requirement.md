# 日本の伝統色クイズ 要求仕様書

## 1. 背景・目的

日本には、自然物や動植物、染料・顔料の由来にちなんだ多彩な伝統色名
（紅・藍・萌黄・山吹色など)が古くから存在する。それぞれの色には名前
だけでなく、名前の由来となった特徴や、歴史・文学・風習にまつわる
トリビアがある。

本アプリは、こうした日本の伝統色の「名前」「特徴」「トリビア」を
クイズ形式で出題し、楽しみながら覚えられるターミナル上の学習ツール
(TUI アプリ)を提供する。

本リポジトリの他のツール(EU Notified Bodies Monitor、
百人一首 決まり字 暗記トレーナー)とは無関係の、独立した学習支援
ツールである。

## 2. 対象ユーザー

- 日本の伝統色の名前・由来・トリビアを覚えたい/知りたい個人ユーザー。
- ターミナル(コンソール)環境で動作するツールを好む/使わざるを得ない
  ユーザー。

## 3. 用語定義

| 用語 | 説明 |
| --- | --- |
| 色名 | 伝統色の名前(例: 「萌黄色」)。 |
| 特徴 | その色が何に由来し、どのような色味かを説明する短い記述。 |
| トリビア | その色にまつわる歴史・文学・風習などの豆知識。 |
| カテゴリ | 色を大まかな系統(赤系・橙系・黄系・緑系・青系・紫系・
  白黒鼠系)に分類したもの。厳密な測色分類ではなく出題の絞り込み用。 |

## 4. 機能要求

### 4.1 色名当てクイズ

- 色見本(スウォッチ)を表示し、4択の中から正しい色名を選ばせる出題が
  できること。

### 4.2 特徴当てクイズ

- 色名(と読み)を表示し、4択の中からその色の特徴として正しい説明文を
  選ばせる出題ができること。

### 4.3 トリビア当てクイズ

- 色名(と読み)を表示し、4択の中からその色にまつわる正しいトリビアを
  選ばせる出題ができること。

### 4.4 4択の作り方

- 誤答選択肢は、正解と紛らわしく学習効果が高くなるよう、可能な限り
  正解と同じカテゴリの色から優先的に選ぶこと。同じカテゴリの候補が
  不足する場合は他のカテゴリの色から補うこと。
- 4つの選択肢の表示順序は毎回シャッフルすること。

### 4.5 カテゴリ指定出題

- 7つのカテゴリ(赤系・橙系・黄系・緑系・青系・紫系・白黒鼠系)の
  いずれかを選び、そのカテゴリに属する色のみを対象に出題できること。
- 各カテゴリの該当色数をメニュー上で確認できること。

### 4.6 苦手優先出題モード

- これまでの解答成績(正答率)に基づき、正答率が低い色ほど出題され
  やすくなるように重み付けした出題を行えること。
- 出題回数が少ない(未出題を含む)色についても、極端に出題されなく
  ならないよう配慮すること。

### 4.7 一覧表示モード

- 全ての色をカテゴリ順に一覧表示できること。
- 各行に色見本(対応端末のみ)・色名・読み・カラーコードを表示する
  こと。
- 一覧はスクロール可能であり、キー操作(上下矢印キー、j/k、
  PageUp/PageDown)で閲覧できること。

### 4.8 成績確認

- これまでの累計正答数・出題数・正答率を表示できること。
- 出題実績のある色のうち、正答率が低い順に一定件数(上限あり)を
  一覧表示し、弱点の把握を支援すること。
- 出題実績が全くない場合は、その旨を表示すること。

### 4.9 成績リセット

- ユーザーの確認(y/N)を経た上で、保存済みの成績をすべて削除できる
  こと。

### 4.10 解答後のフィードバック

- 解答の正誤にかかわらず、解答直後に正解の色名・色見本・特徴・
  トリビアをまとめて表示すること(正解時だけでなく不正解時にも
  学習になるようにするため)。

## 5. 非機能要求

- 追加の外部ライブラリに依存せず、Python 標準ライブラリのみ(特に
  `curses`)で動作すること。
- Linux 環境のターミナル上で動作すること(Windows 固有の対応は対象
  外)。
- カラー対応端末では色見本を実際の色に近い形で表示すること。ただし
  カラー非対応端末でもクラッシュせず、カラーコードのテキスト表示に
  自動的に切り替わること。
- 一般的なターミナルサイズ(80桁×24行程度)で正しく表示できること。
  また、それより狭いターミナル幅でも、表示が乱れて他の行と視覚的に
  混ざる(文字化けのように見える)ことがないこと。ターミナル幅・高さ
  が極端に狭い場合に情報が一部表示しきれないこと自体は許容する。
- 全角文字(漢字・ひらがな)を含む日本語テキストを正しく描画できる
  こと。長い特徴・トリビアの文章は端末幅に応じて折り返し表示できる
  こと。
- 成績データはアプリ終了後も保持され、次回起動時に引き継がれること
  (既定の保存先: `~/.iroquiz_stats.json`)。保存先は起動オプション
  (`--state-file`)で変更できること。
- 想定外のキー入力や、想定より小さいターミナルサイズによってアプリ
  がクラッシュしないこと。
- `python -m iroquiz` として起動できること。

## 6. 対象外(スコープ外)

- ネットワーク通信・外部サービス連携。
- GUI(グラフィカルなウィンドウ)版の提供。
- 複数ユーザーでの成績共有・ランキング機能。
- 色の正確な測色・カラーマネジメント(本アプリのカラーコードは目安の
  近似値であり、印刷物等の厳密な色再現を保証するものではない)。
