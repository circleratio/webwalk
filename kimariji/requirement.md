# 百人一首 決まり字 暗記トレーナー 要求仕様書

## 1. 背景・目的

競技かるたでは、読み手が上の句を読み上げている途中で、それまでに読まれた
文字列だけで100首中どの札か一意に特定できる。この「一意に特定できる最小の
文字列」を決まり字と呼ぶ。決まり字を覚えることは競技かるたの基本であり、
上達のためには100首すべての決まり字を体系的に暗記する必要がある。

本アプリは、この決まり字の暗記を支援するための、ターミナル上で動作する
学習ツール（TUI アプリ）を提供する。

本リポジトリの他のツール（EU Notified Bodies Monitor）とは無関係の、
独立した学習支援ツールである。

## 2. 対象ユーザー

- 競技かるたの決まり字を覚えたい個人ユーザー。
- ターミナル（コンソール）環境で動作するツールを好む/使わざるを得ないユーザー。

## 3. 用語定義

| 用語 | 説明 |
| --- | --- |
| 上の句 | 和歌の五・七・五の部分。読み手が読み上げる部分。 |
| 下の句 | 和歌の七・七の部分。取り札に書かれている部分。 |
| 決まり字 | 上の句の頭から数文字読まれた時点で、他の99首と重複せず一意に
  歌を特定できる最小の文字列。 |
| ○字決まり | 決まり字の文字数による分類（一字決まり〜六字決まり）。標準的な
  内訳は一字決まり7首・二字決まり42首・三字決まり37首・四字決まり6首・
  五字決まり2首・六字決まり6首（大山札）の計100首。 |

## 4. 機能要求

### 4.1 出題モード（ランダム／全体）

- 100首の中からランダムに1首を選び、上の句の読み（ひらがな）を1文字ずつ
  段階的に表示できること。
- ユーザーは好きなタイミングで、その時点までに表示された文字列から歌を
  特定し、歌番号（1〜100）を入力して解答できること。
- 解答後、正誤・正解の歌番号・歌人・上の句/下の句（漢字表記）・実際の
  決まり字とその文字数・ユーザーが解答時点で表示していた文字数を表示する
  こと。
- 現在の問題をスキップする手段、および出題モードからメインメニューへ
  戻る手段を提供すること。

### 4.2 出題モード（決まり字の文字数指定）

- 一字決まり〜六字決まりのいずれかの文字数グループを選択し、そのグループ
  に属する歌のみを対象に 4.1 と同様の出題を行えること。
- 各グループの該当首数をメニュー上で確認できること。

### 4.3 苦手優先出題モード

- これまでの解答成績（正答率）に基づき、正答率が低い歌ほど出題されやすく
  なるように重み付けした出題を行えること。
- 出題回数が少ない（未出題を含む）歌についても、極端に出題されなくなら
  ないよう配慮すること。

### 4.4 一覧表示モード

- 全100首を決まり字の文字数順（グループ内は決まり字の文字コード順、
  歌番号順）に一覧表示できること。
- 各行に歌番号・決まり字・上の句（漢字）を表示すること。
- 一覧はスクロール可能であり、キー操作（上下矢印キー、j/k、
  PageUp/PageDown）で閲覧できること。

### 4.5 成績確認

- これまでの累計正答数・出題数・正答率を表示できること。
- 出題実績のある歌のうち、正答率が低い順に一定件数（上限あり）を一覧
  表示し、弱点の把握を支援すること。
- 出題実績が全くない場合は、その旨を表示すること。

### 4.6 成績リセット

- ユーザーの確認（y/N）を経た上で、保存済みの成績をすべて削除できる
  こと。

### 4.7 データの正確性

- 各歌の決まり字は、実際に「上の句の読みが他の99首と重複しなくなる
  最小の文字数」という定義に基づいて算出されたものであり、内容の正しさ
  は競技かるたで知られる標準的な内訳（一字決まり7・二字決まり42・
  三字決まり37・四字決まり6・五字決まり2・六字決まり6、合計100）と
  一致することをもって担保すること。

## 5. 非機能要求

- 追加の外部ライブラリに依存せず、Python 標準ライブラリのみ（特に
  `curses`）で動作すること。
- Linux 環境のターミナル上で動作すること（Windows 固有の対応は対象外）。
- 一般的なターミナルサイズ（80桁×24行程度）で正しく表示できること。
  また、それより狭いターミナル幅でも、表示が乱れて他の行と視覚的に
  混ざる（文字化けのように見える）ことがないこと。ターミナル幅が
  極端に狭い場合に情報が一部表示しきれないこと自体は許容する。
- 全角文字（漢字・ひらがな）を含む日本語テキストを正しく描画できる
  こと。
- 成績データはアプリ終了後も保持され、次回起動時に引き継がれること
  （既定の保存先: `~/.kimariji_stats.json`）。保存先は起動オプション
  （`--state-file`）で変更できること。
- 想定外のキー入力や、想定より小さいターミナルサイズによってアプリが
  クラッシュしないこと。
- `python -m kimariji` として起動できること。

## 6. 対象外（スコープ外）

- ネットワーク通信・外部サービス連携。
- GUI（グラフィカルなウィンドウ）版の提供。
- 複数ユーザーでの成績共有・ランキング機能。
- 決まり字以外の要素（下の句の暗記、歌人名の暗記など）を主目的とした
  出題モード。
